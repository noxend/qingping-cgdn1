# Template

The starting point for a plugin of your own: a line of text from a setting, the time and the
temperature, redrawn once a minute. Copy the folder and follow [../README.md](../README.md#quick-start).

| File | What it is |
|---|---|
| `plugin.c` | the code, commented call by call |
| `plugin.json` | id, names, category, hosts and the one setting, `text` (default `Hello`) |
