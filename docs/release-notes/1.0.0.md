# CGDN1 firmware 1.0.0

The first release of the custom firmware for the Qingping Air Monitor Lite (CGDN1). It replaces the
stock Qingping firmware on the ESP32.

## What is new compared to the stock firmware

- Screens you flip through by sliding a finger along the touch strip: temperature, humidity, CO2,
  PM2.5, PM10, a clock, and a map of air raid alerts in Ukraine's regions.
- Each screen is a plugin that can be turned on or off and set up from the web interface: time and
  date format, CO2 levels for the yellow and red indicator, the region the alert indicator follows.
  Any of them can be deleted and installed again from the store, and a plugin of your own installs
  from a `.wasm` file (plugins/README.md). Plugin names, descriptions and settings
  are in English and Ukrainian.
- A menu on the device itself: hold the power button for a second. Power off, Restart, Wi-Fi
  setup, Factory reset with a confirmation, and Info with the version, IP address, network and
  uptime.
- Night mode: on a schedule, the screen dims or turns off and the indicator dims.
- A time zone setting: Kyiv by default, or one of a short list of zones in Europe, America, Asia
  and Australia, with daylight saving time.
- Burn-in protection for the OLED panel: the picture moves by a pixel every minute.
- Battery protection: on battery the device shows "Low battery" and powers off when the cell drops
  under 3.3 V, and it does not start on a cell under 3.4 V, so a flat battery is not drained
  further.
- A web interface at `http://cgdn1.local/`, in Ukrainian and English: screens with live previews,
  night mode, Wi-Fi, firmware updates.
- No password is built into the firmware: the setup access point's password is made on the device
  and shown in its menu, and the device password is chosen at setup and stored as a hash.
- One sign-in: the web interface asks for the device password once, and the browser stays signed
  in for 30 days after its last visit, through restarts and updates. Sign out is on the System
  page. Tools send the password as `Authorization: Bearer`.
- Firmware updates from the web interface: the device checks for releases every hour, Update
  installs one, and automatic updates at 04:00 can be turned on. Images are signed, and an update
  that is not healthy within its first minutes rolls back by itself.
- Wi-Fi setup through the device's own access point, `CGDN1-setup-XXXX` at `http://10.47.0.1/`,
  which comes back whenever the home network is lost.

## How to update

- **From the stock firmware**: not over the air. The first install goes through the ESP32's serial
  port with the case open; see [docs/install.md](../install.md).
- **From a 1.0.0 release candidate**: the web interface's header shows the new version within an
  hour of the release. Open the System page and press Update on the Update card.

## Known limitations

- No Apple Home (HomeKit), and no Qingping or Mi Home app.
- The device password can be changed only by a factory reset and a new setup.
- No battery level on the screen or in the web interface, and no charging screen.
- On USB power the device cannot cut its own power: after a power off it stays dark until the next
  hold of the power button.
- The device menu is in English only.
- The setup access point needs a client with PMF (802.11w).
- Without internet access the device serves the web interface built into the firmware, which may be
  older than the hosted one.
